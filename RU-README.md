# The Powder Toy — русская локаль (RU)

Русифицированная сборка **The Powder Toy** на базе официальных исходников
**v100.1 (build 400)**. Изменения относятся только к текстам интерфейса
и шрифту — физика, логика и геймплей не тронуты.

## Что сделано

- Переведены на русский:
  - HUD и главное меню;
  - все основные окна: настройки, вход в аккаунт, браузеры сохранений,
    профиль, поиск, рендер, публикация, просмотр;
  - все диалоги, информационные сообщения и тексты ошибок;
  - 11 служебных инструментов;
  - 19 стен и категории меню;
  - 195 элементов (имена и описания) в `src/simulation/elements/*.cpp`;
  - окна входа, профиля, поиска, сохранения и т.д.
- Расширен шрифт `resources/font.bz2` типографикой: `– — … • №`
  (утилита `fonttool.py`).
- В `src/common/String.h` добавлен безопасный конвертер `String::FromUtf8OrAscii`:
  строковые литералы в UTF-8 корректно декодируются в Unicode, а служебные
  байты цветовых тегов (`\x0F\xEF\xEF…`) сохраняются как раньше.

## Системные требования для сборки

- macOS с macOS SDK; компилятор с поддержкой C++20 (например, `clang` ≥ 16;
  системный clang 12 на Catalina не поддерживает `-std=c++20` целиком —
  используйте `clang-mp-17` из MacPorts).
- Зависимости: SDL2, libcurl, libpng, bzip2, FFTW3f (`fftw3f`), jsoncpp.
- Lua опционален (`-Dlua_variant` / `-Dlua`: none, lua5.1, lua5.2, luajit).

## Сборка

```sh
meson setup build -Dlua=none
ninja -C build
```

Если FFTW3f/jsoncpp собраны локально (например, из-за недоступности
пакетного менеджера):

```sh
export PKG_CONFIG_PATH=$PWD/fftw-install/lib/pkgconfig:$PWD/jsoncpp-install/lib/pkgconfig
```

macOS: для генерации `.app` бандла используйте сгенерированный
`build/resources/Info.plist` и структуру `Contents/{Info.plist,MacOS,Resources}`.

> ВАЖНО: на macOS сборка должна использовать Objective-C++ компилятор,
> поддерживающий C++20, иначе файл `src/common/clipboard/Cocoa.mm` не соберётся:
> `OBJCXX=/opt/local/bin/clang++-mp-17`.
